# geometry-dash-fly
 Fly Dash — это хардкорный платформер, где обычная комнатная муха бросает вызов законам физики и пытается пройти уровень в стиле Geometry Dash.  Забудьте о кубах и шипах — теперь главный герой жужжит, летает и разбивается о препятствия. Помогите мухе выжить в мире, который явно против неё настроен (и против её сородичей с мухобойками).
